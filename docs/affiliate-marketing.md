# 서버별 사이트와 제휴마케팅

2026-10-28 메뉴 정리. `/`가 서버별 사이트 작업공간이며 `/servers`는 `/`로 이동합니다. 이전 `/affiliate`, `/banner-management` 페이지는 `/affiliate-marketing`으로 이동합니다. 기존 관리 데이터·배너 런타임 API·통계 수집 작업은 보존했습니다.

제휴마케팅은 별도 Affiliate OS의 관리자 접속 주소를 저장하고 새 창으로 여는 페이지입니다. 기본 주소 `http://127.0.0.1:18787/admin`은 이 PC에서 Affiliate OS 프로젝트의 `open-ovh.cmd`로 SSH 터널을 연 경우에만 사용할 수 있습니다. 다른 기기에는 해당 기기의 접속 환경이 필요합니다. 공개 URL에서 이 로컬 주소를 연다는 것만으로 SSH 터널이나 서비스가 자동 시작되지는 않습니다.

주소는 이 브라우저의 localStorage에만 저장합니다. HTTPS `/admin` 또는 로컬 HTTP `/admin`만 허용하고 로그인 정보·쿼리·해시는 거절합니다. 로그인·계정 관리는 Affiliate OS에서 수행하며 이 대시보드에는 키·계정·쿠키를 저장하거나 전달하지 않습니다. URL 저장은 서비스 가동, 인증, API 연결 또는 게재 승인의 증거가 아닙니다.

API 원장/승인/클릭/정산 동기화와 공개 관리자 도메인·HTTPS 접속은 이번 메뉴 변경의 완료 범위가 아닙니다. 기존 앱의 iframe 차단·세션·CSRF를 유지합니다. 페이지는 바로가기 상태와 미연결을 명시하며 실제 건수나 수익을 추정하지 않습니다.

검증: `pnpm test`, `pnpm lint`, `pnpm type-check`, `pnpm build`, `pnpm test:e2e`. 브라우저 테스트는 기존 HTTP 서버가 없으면 로컬 개발 서버를 시작합니다. 운영 SSH 접속 성공 여부와는 별도입니다.
