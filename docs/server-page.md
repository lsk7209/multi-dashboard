# 서버별 사이트 페이지

- 요청: 대시보드 메뉴에 OVH·Turbo1·Turbo2만 간단히 볼 수 있는 페이지 추가.
- 경로: `/servers`, 공통 상단 메뉴 `서버별 사이트`.
- 디자인: 기존 색상·글꼴·헤더 유지. 데스크톱은 서버별 세 열, 모바일은 한 열. 서버명·사이트 수·도메인 링크와 검색만 표시한다.
- 데이터: 기존 `site-inventory.json`의 세 서버 분류만 표시. Vercel/미확인/이전 원본을 섞지 않는다. 목적지 미확인 Turbo 이전 항목은 숫자 안내와 전체 상세 링크만 제공한다.
- 서버/DNS/계정 데이터 변경 없이 기존 수집 현황을 표시한다.
