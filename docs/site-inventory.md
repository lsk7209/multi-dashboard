# 사이트 서버·연결 현황

대시보드 `서버·연결` 탭 (`/#inventory`)에서 서버와 공식 애드센스 상태를 필터링하고 도메인·GA4 속성·GSC URL을 검색한다.

## 수집

- `pnpm dashboard:refresh`: GA4/GSC 통계, 운영 신호, 공식 애드센스, Google 속성 목록과 호스팅 현황을 순서대로 갱신한다.
- `pnpm inventory:refresh`: 공식 애드센스 → Google 연결 목록 → DNS/HTTPS 및 계정 증거 대조.
- `pnpm inventory:reconcile`: 이미 수집한 필수 소스와 현재 공개 DNS/HTTPS를 대조한다. 필수 파일이 없거나 손상됐으면 새 현황으로 덮어쓰지 않는다.
- 기존 인증 파일을 사용하며 값은 출력하지 않는다. 경로는 `ADSENSE_OAUTH_CLIENT_PATH`, `ADSENSE_TOKEN_PATH`, `GOOGLE_BINDINGS_CREDENTIAL_PATH`로 바꿀 수 있다. Google 서비스 계정 JSON은 `GCP_SA_KEY_JSON`도 지원한다.

원본 계정 목록은 Git 제외 경로 `.local/site-inventory/`에만 저장한다. 공개 자료에는 계정 리소스 ID, 속성 표시 이름, 스트림 리소스 ID, 권한 수준, 서버 사용자·경로·인증값을 포함하지 않는다. 대시보드에 필요한 도메인과 기술 연결 식별자, 상태 및 확인 시각만 남긴다.

## 판정 경계

- 호스팅은 시스템 DNS·Google DNS와 HTTPS HEAD 응답 기준이다. 서로 다른 CDN 엣지 IP만으로 이전 중이라고 판정하지 않는다. 서로 다른 원본 서버 응답이나 DNS 존재 여부가 충돌하면 DNS 불일치로 표시한다.
- cPanel `DomainInfo` 계정 증거는 공개 경로와 별도로 표시한다. DNS가 없는 도메인도 서버 계정에 설정된 사실과 공개 연결 미확인을 함께 보여준다. 계정 증거는 7일 후 자동 사용하지 않는다.
- Turbo1/2 계정 목록은 2026-10-18 읽기 전용 인증 조회. Kickstart는 네 계정만 확인했으며 전체 잔존 계정 조사는 미완료다. 공개 파일은 백업·이전용 별칭을 생략한 목록이다.
- GA4의 동일 도메인 다중 속성은 합산하지 않는다. 속성의 실제 웹 스트림 도메인이 설정과 다르면 1일 사용자 수를 미확인으로 표시한다. Google 목록 발견만으로 수집 대상을 활성화하지 않는다.
- GSC 속성 목록에 있다고 통계 조회 권한이 있다는 뜻은 아니다. 2026-10-18 `alt.coinyo.kr`, `bit.coinyo.kr`, `jeompolab.com`, `lo.klick.kr`, `ko.klick.kr`은 목록에 있으나 `siteUnverifiedUser`이고 통계 조회가 권한 오류다. 계정 권한은 변경하지 않았다.
- 애드센스는 공식 Sites API 전체 페이지의 정확한 도메인을 대조한다. 코드·ads.txt·수익 유무로 승인을 추론하지 않으며 상위 도메인 승인을 서브도메인의 정확한 승인으로 표시하지 않는다. 목록 없음은 거절 상태가 아니다. 수익화 제외 설정과 은퇴 사이트 경계는 유지한다.
- 공식 승인 증거는 24시간만 현재 상태로 표시한다. 현재 GitHub 예약 작업에는 애드센스 OAuth 인증을 추가하지 않았다. 예약 작업은 DNS·Google 목록을 갱신하지만 공식 계정 증거가 만료되면 승인 상태를 미확인으로 표시한다. 로컬 `pnpm inventory:refresh`는 기존 인증으로 공식 목록도 다시 조회한다.
- 이 현황은 이전 완료·DNS 변경·원본 삭제·계정 재등록을 승인하거나 실행하지 않는다.

## 2026-10-18 확인

GA4 속성 156개·웹 스트림 158개, GSC 속성 140개를 조회했다. 공식 애드센스 계정 전체는 12개(READY 11, GETTING_READY 1)다. 공개 관리 도메인 자료에는 운영 대상과 관련된 행만 남기며, 제외/은퇴/비관리 행을 큐에 넣지 않는다.

`coinyo.kr`의 `coinyo-2` 설정 속성 `536352221`은 웹 스트림 도메인이 `coinyo.knewstory.kr`이어서 불일치로 표시했다. 계정 등록과 원본 통계는 변경하지 않았다. `texturb.com`은 조회 시점·리졸버에 따라 Vercel/OVH 응답이 관측되어 최종 대조 결과와 시각을 함께 보존한다.
`data/site-inventory-domains.json`은 이번 조사에서 대시보드에 포함한 도메인의 명시적 범위다. 계정 전체 원본은 비공개로 보존하고 공개 수집 결과는 이 범위와 설정 도메인으로 제한한다. 승인 목록의 공개 대조 범위 밖에서는 목록 없음 대신 미확인으로 표시한다.
